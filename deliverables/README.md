# Deliverables

- `presentations/` contains the latest peer-facing and client-facing PowerPoint
  files retained at consolidation.
- `report/` contains the LaTeX technical report source, figures, and compiled
  PDF.
- `generated/` is reserved for regenerable reporting outputs and is ignored by
  Git.

Rendered slide inspection images and `.inspect.ndjson` files were intentionally
excluded because the editable PowerPoint files are authoritative.
