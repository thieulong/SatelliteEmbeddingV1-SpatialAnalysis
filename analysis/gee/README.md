# Google Earth Engine Source

`gee_export_sentinel2_annual.js` is the retained optional visual-imagery export.
It creates annual 10 m true-colour Sentinel-2 composites for 2017-2025 using
surface reflectance, Cloud Score+ masking and an annual median.

This is not the missing Earth Engine source that produced the 64-D embedding
change rasters. Export and version that source separately before national
scaling.
