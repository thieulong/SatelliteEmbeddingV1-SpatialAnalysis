# Optional Research

This directory contains experiments that informed project decisions but are
not part of the production pipeline.

`external_landcover/` contains the DEA Fractional Cover, Dynamic World, and
Esri Annual Land Cover evaluations. Esri produced useful broad-family
cross-checks but was not retained as a required application evidence layer.
Generated research outputs belong under ignored `research/outputs/`.

`ndvi_comparison_study_design.md` retains the proposed research question and
validation design comparing embedding-space change with traditional NDVI.
