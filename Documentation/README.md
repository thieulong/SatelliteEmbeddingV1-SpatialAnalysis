# AusHabitat Documentation

This documentation describes the consolidated project state, with the Bass
Coast regression checkpoint frozen on 2026-09-03. Historical phase names
remain inside existing output filenames, but current work should use the eight
canonical stages in `02_CANONICAL_PIPELINE.md`.

| Document | Purpose |
| --- | --- |
| `01_PROJECT_OVERVIEW.md` | Scope, current milestone, architecture, and counts |
| `02_CANONICAL_PIPELINE.md` | Methods, stage inputs/outputs, equations, and commands |
| `03_RESULTS_AND_LIMITATIONS.md` | Verified findings and evidence boundaries |
| `04_DATA_AND_REPRODUCTION.md` | Local data layout, retention, environment, and checks |
| `05_WEB_APPLICATION.md` | App data model, controls, imagery, and deployment |
| `06_DECISIONS_AND_ROADMAP.md` | Decision history, stakeholder direction, and future work |
| `07_BASS_COAST_REGRESSION_BASELINE.md` | Frozen checkpoint and regression contract |
| `08_NATIONAL_SCALING_PILOT_2026-09-21.md` | Bounded mainland/Tasmania boundary, site, and export pilot; not a national result |
| `09_NATIONAL_EVIDENCE_PILOT_2026-09-30.md` | Follow-up sampling design, measured compression and boundary screening, and export checkpoint |
| `10_STORAGE_RETENTION_AND_TEAMS_TEST_2026-10-28.md` | Product-retention policy and checksum-verified RMIT Teams storage test |
| `SOURCES_AND_PROVENANCE.md` | Authoritative external sources and version risks |
| `GLOSSARY.md` | Plain-language terminology |
| `MIGRATION_CHECKLIST.md` | Old-machine and new-machine transfer procedure |
| `CLEANUP_MANIFEST.md` | What consolidation retained, archived, or discarded |

Machine-readable summaries are available in `handover_summary.json` and
`local_data_inventory.csv`; the national pilot's exploratory site samples are
in `national_pilot_site_stats_2026-09-21.csv`, and the reviewed fine-cell
recovery plan is in `national_recovery_fine_inventory_2026-10-05.csv`. Compact
results supporting the Bass Coast headline numbers are stored under
`analysis/reference_outputs/`.
